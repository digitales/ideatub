## The problem

UK local businesses lose enquiries in two invisible ways:

1. **Google Business Profile neglect** — weak reviews, missing photos, incomplete listings while competitors capture Maps visibility worth **£3–25 per paid click**.
2. **Website accessibility failures** — WCAG violations that block bookings, with **EAA/EHRC enforcement** now live for professional services firms.

Agencies and freelancers waste hours manually prospecting, auditing one site at a time, and writing cold emails that prospects dismiss as generic sales noise.

---

## The solution

**nthdesigns Prospect Scanner** finds weak local businesses, scores them on GBP + accessibility, generates a **shareable proof report**, and drafts **personalised outreach** — in one workflow.

> *Find → Score → Prove → Convert*

---

## How it works (60 seconds)

| Step | What happens |
|------|----------------|
| **1. Discover** | Run a niche + city search (e.g. “private dentist, Birmingham”) or audit a single URL |
| **2. Score** | Dual-signal weakness ranking: GBP gaps vs local #1 competitor + axe-core/Lighthouse violations |
| **3. Prove** | Auto-generate an unlisted report (`/r/{token}`) — grade, violations, screenshots, competitor comparison |
| **4. Convert** | AI drafts outreach with the right pitch angle; embed report link; prospect books via report CTA |

## Homepage recommendations

The live homepage (`/` on the scanner app) sells **audits to UK SMEs**, not the **prospecting tool to agencies**. Two audiences, two possible surfaces.

### Already on the homepage (SME audit buyer)

| Section | Covers |
|---------|--------|
| Hero + AuditWidget | Free scan CTA, dual-signal promise |
| HowItWorks | WCAG + GBP dual signal |
| SampleReportExcerpt | Verifiable report proof |
| WhyNow | EHRC / WCAG 2.2 urgency |
| Evidence | Before/after fix examples |
| Compare | vs Lighthouse / SEMrush / Ahrefs |
| Pricing | Free audit / Fix package / Retainer |
| FAQ | Trust, accuracy, data handling |

### Add to homepage (SME audience — high impact)

These strengthen conversion for **business owners** receiving or seeking an audit:

1. **GBP cost-of-ads framing** (HowItWorks or new “Visibility” strip)  
   One stat line: *“Dental practices in Birmingham pay ~£6.50 per Google Ads click. A strong GBP delivers equivalent visibility organically.”* Uses CPC benchmark story without exposing internal tooling.

2. **Booking path clarity** (SampleReportExcerpt or FooterCTA)  
   Show report → book 30-min call flow explicitly. The product has inline booking; homepage should mirror it.

3. **Dominant-signal callout** (HowItWorks)  
   Short note: *“We tell you whether to fix the website, the Google profile, or both first.”* Matches the combined score UX prospects see in reports.

4. **Industry specificity** (Testimonials or new “Who this is for” strip)  
   Dental, legal, hospitality — aligns with outreach strategy and builds credibility vs generic “any business.”

5. **Report screenshots in SampleReportExcerpt**  
   Marketing analysis emphasises screenshot proof; sample report section currently shows violation text but not the screenshot UX — add one annotated screenshot panel.

6. **EAA / EU-facing angle** (WhyNow — one paragraph)  
   Complement EHRC UK focus with European Accessibility Act for businesses serving EU customers.

### Add only if launching agency/SaaS surface

Do **not** clutter the SME homepage with operator features. Use a separate `/for-agencies` page or footer link for:

| Feature | Why separate |
|---------|--------------|
| Niche opportunity scanner | Operator-only market triage |
| AI outreach generation | Internal sales motion, not SME-facing |
| Prospect lists / warm leads / CRM | B2B tool positioning |
| MCP / Connected apps | Technical differentiator for power users |
| SaaS pricing tiers (£39–149) | Conflicts with current service pricing (£0 / £2,400 / £900) |
