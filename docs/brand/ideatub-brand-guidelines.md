
# IdeaTub Brand Guidelines

Version: 1.0  
Last updated: 2026  

This document defines the visual and design principles for **IdeaTub**.

It should be used when building:

- product UI
- landing pages
- marketing materials
- documentation
- AI-generated assets

The goal is to ensure IdeaTub maintains a **consistent calm, thoughtful design language**.

---

# Brand Concept

IdeaTub is a **calm archive for ideas**.

It captures thoughts before they disappear and stores them as structured, searchable memory.

The product is **not a productivity tool**.  
It is **thinking infrastructure**.

---

# Brand Personality

IdeaTub should feel:

• Calm  
• Thoughtful  
• Intelligent  
• Minimal  
• Trustworthy  

Avoid:

• hype-driven startup design  
• aggressive productivity UI  
• loud colour palettes  

The interface should feel closer to **checking the weather** than managing tasks.

---

# Core Brand Metaphor

IdeaTub represents a **channel for ideas**.

Concept:

Idea → Capture → Structured memory → Retrieval

The logo and illustrations reflect **flowing pathways** similar to:

- neural pathways
- data pipes
- memory channels

---

# Logo

## Primary logo

The IdeaTub logo consists of:

1. Flowing channel icon
2. Wordmark

[ icon ] IdeaTub

The icon represents a **continuous idea channel**.

### Logo rules

The logo must:

• maintain original proportions  
• keep sufficient whitespace  
• not be stretched or recoloured  

### Minimum spacing

logo clear space = icon width

### Variants

Allowed variants:

• Full colour  
• Monochrome  
• White on dark  

---

# Icon

The icon represents the **idea channel loop**.

Usage:

• favicon  
• app icon  
• navigation logo  
• social avatar  

The icon must remain recognisable at small sizes.

# Gradient

Marketing materials may use gradient:

Teal → Indigo → Violet

#2A8C8C → #1E2547 → #6D6AF7

---

# Layout Principles

IdeaTub interfaces must prioritise **clarity and calmness**.

Rules:

• generous whitespace  
• minimal UI chrome  
• simple layouts  
• predictable interaction  

Avoid:

• dashboards  
• dense information blocks  
• gamification  

---

# Interface Structure

Standard layout pattern:

---------------------------------
Search / Capture
---------------------------------

Recent thoughts

Thought content
Metadata
Tags
---------------------------------

Capture should always be **fast and prominent**.

---

# Microcopy

IdeaTub uses **thoughtful language**.

Prefer:

| Instead of | Use |
|-----------|----|
Save | Store thought |
Search | Find a memory |
Notes | Thoughts |
Archive | Memory |

---

# Tagline

Primary tagline:

Alternate:

---

# Illustration Style

Illustrations should use:

• flowing lines  
• neural pathways  
• pipelines  
• minimal diagrams  

Style characteristics:

• thin lines  
• soft gradients  
• calm colours  

Avoid:

• cartoon graphics  
• stock photography  
• heavy 3D renders  

---

# Motion Design

Subtle motion is encouraged.

Examples:

• dot travelling through idea channel  
• flowing neural path animation  
• gentle fade transitions  

Avoid fast or distracting motion.
