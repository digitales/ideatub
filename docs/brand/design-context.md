
# IdeaTub Design Context

This file provides context for AI tools (Cursor, ChatGPT, Claude) when generating UI for IdeaTub.

## Design Philosophy

IdeaTub is a calm personal archive for ideas.

Design should feel:

- calm
- thoughtful
- minimal
- intelligent

Avoid dashboard-style productivity interfaces.

The interface should feel closer to **Apple Notes or Linear** than Notion or ClickUp.

## Visual Principles

1. Large whitespace
2. Minimal UI elements
3. Clear hierarchy
4. Simple layouts
5. Calm colour usage

## Colour Tokens

Primary: #1E2547  
Accent: #2A8C8C  
Secondary: #6D6AF7  
Background: #F5F7FB  
Text: #5B6472

## Typography

Primary font: Inter

Weights used:

- 400 (body)
- 500 (buttons)
- 600 (headings)

## Interface Pattern

Typical page structure:

Search / Capture input at the top

Recent thoughts list below

Optional metadata panel on the side

Capture input should always be prominent.

## Illustration Style

Use:

- flowing line diagrams
- neural pathways
- idea pipelines

Avoid:

- cartoon characters
- stock photography
- heavy 3D graphics

## Motion

Allowed motion:

- subtle fades
- slow flowing line animations
- idea dot travelling through pipeline

Avoid fast or distracting animation.

## Microcopy

Prefer language like:

Store thought  
Find a memory  
Capture idea  

Avoid task-management language.
