# Brainstorming outputs (Panning for Gold)

Panning for Gold writes working files here when you process meetings or brain dumps with the prompts in **`resources/prompts/panning-for-gold-*.md`**.

Typical artefacts:

- `YYYY-MM-DD-<slug>-inventory.md` — extracted threads (Phase 1)
- `YYYY-MM-DD-<slug>-gold-found.md` — verdicts and synthesis (Phase 3)
- `evaluations/` — optional per-thread evaluation notes (Phase 2)

See **`resources/prompts/panning-for-gold-core.md`** and **`docs/superpowers/specs/2026-04-29-panning-for-gold-ideatub-design.md`**.
